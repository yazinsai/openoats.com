# openoats.com

Landing page for [OpenOats](https://github.com/yazinsai/OpenOats), the minimal meeting recorder for Mac. Next.js 16 (App Router), Tailwind 4, bun.

```bash
bun install
bun run dev      # http://localhost:3000
bun run build    # production build (output: standalone)
```

- Copy and links: `src/lib/site.ts`, FAQ in `src/lib/faq.ts`.
- The version badge reads the latest GitHub release (`src/lib/release.ts`, revalidated hourly). Download buttons point at `releases/latest/download/OpenOats.dmg`.
- Product shots live in `public/shots/` (2x webp captured from the app). The OG image is generated by `src/app/opengraph-image.tsx`.
- Palette and type follow the app's paper-and-moss theme (`src/app/globals.css`).
